The Student Behind the Terminal

Hi there! I'm Amrendra Yadav. I'm currently navigating my 1st year of college at the Indian Institute of Technology Jodhpur (IIT Jodhpur), with my home base in Delhi, India.

While many start programming by grabbing pre-made templates and stitching libraries together, I've always had an itch to look under the hood. I wanted to know: How does a computer actually turn numbers into 3D pixels? How does an index make an SQL query a thousand times faster? What happens to memory allocations when a server handles millions of packets?

That curiosity drove me into low-level C++, memory allocators, computer graphics via OpenGL, and real-time backend streaming in Python. When I build web apps, I love writing pure, bespoke CSS and JavaScript rather than relying on bloated 50MB frameworks. Every interaction you see here is written by hand, line by line.
